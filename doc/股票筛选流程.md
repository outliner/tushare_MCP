# 股票筛选流程 (集成 MCP 工具)

## 1. 历史数据与盘后策略分析 (T-1日)

此阶段的目标是基于历史数据对市场进行“体检”，锁定具有 Alpha 收益的行业，并初步筛选标的池。

1.  **大盘宏观扫描:**
    *   使用 `macro_scan` 分析全市场量能、风格（大小盘剪刀差）及整体赚钱效应。判断市场是处于冰点期还是活跃期。
2.  **行业/板块 Alpha 分析:**
    *   **申万二级行业:** 使用 `rank_l2_sectors_by_alpha` 找出 alpha 得分最高的行业；使用 `rank_l2_sectors_alpha_velocity` 观察哪些行业排名正在快速上升。
    *   **东财概念板块:** 使用 `rank_concepts_by_alpha` 和 `rank_concepts_alpha_velocity` 识别当前最强势的概念热点。
3.  **异动与潜力扫描:**
    *   使用 `scan_concepts_volume_anomaly` 发现成交量异动（MA3/MA10 > 1.8）且涨幅适中（2%~8%）的右侧启动板块。
4.  **机构动向扫描:**
    *   使用 `inst_track_scan` 结合调研热度和龙虎榜机构净买入，锁定机构偏好的“黄金赛道”。
5.  **初步标的筛选:**
    *   **数据准备:** 运行 `collect_stock_data` 采集 T-1 日所有个股的基础指标（换手率、筹码、融资等）。
    *   **多模式筛选:** 根据 T-1 日的大盘风格，调用 `filter_stocks`。如果要深挖特定强势板块，可传入 `sector_code`（如：申万二级代码或东财代码）。
    *   **输出:** 得到一份针对第二天的“待选标具体池”。

## 2. 日内实时监控与决策 (T日)

此阶段的目标是通过实时快照分析板块强度，验证 T-1 日的预判，并寻找日内共振机会。

1.  **关键时间点监控 (10:00 / 12:00 / 14:40):**
    *   **横向板块扫描:** 使用 `scan_realtime_strong_sectors` 获取当前所有板块的实时强度排名，观察资金流向。
    *   **纵向健康度分析:** 对排名靠前的板块调用 `analyze_sector_health`，检查其是否有“分时背离”或“量价背离”，判断板块冲高的可持续性。
    *   **分时趋势确认:** 针对特定热点行业（如：人形机器人），调用 `analyze_sector_today_trend_api` 查看其分时强度评分和 Momentum 走势。
2.  **个股选定与买入 (14:40 附近):**
    *   调取实时最强板块的成分股 (`get_stocks_by_sector`)。
    *   将实时热点成分股与 T-1 日标的池取交集。
    *   结合成交量比率、封板意愿等实时指标锁定最终买入标的。

## 3. 持仓处理与卖出决策 (T+1日)

1.  **开盘/盘中监控 (10:00 附近):**
    *   继续使用 `scan_realtime_strong_sectors` 和 `analyze_sector_health` 监控持仓个股所属板块的走势。
    *   如果所属板块健康度下降（出现背离或强度排名大幅后移），结合个股表现决定是否减仓或止盈卖出。
