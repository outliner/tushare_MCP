# 15分钟线筛选方案整体流程

## 📋 方案概述

本方案采用**两阶段筛选**策略，结合日线漏斗策略和15分钟线尾盘体检，用于T+1尾盘选股。

---

## 🔄 完整流程架构

```
数据准备阶段
    ↓
初步筛选阶段（日线漏斗策略）
    ↓
15分钟线二次筛选（尾盘体检）
    ↓
最终输出
```

---

## 阶段一：数据准备阶段

### 1.1 T-1数据采集 (`batch_data_collector.py` / `data_collector.py`)

**目标**：采集T-1日（前一交易日）的全市场基准数据，存储到 `t1_data` 表

**采集数据源**：
- **基础行情**：日线行情 (`daily`) + 每日指标 (`daily_basic`)
  - `pre_close`: 前收盘价
  - `pre_vol`: 前成交量（手）
  - `pre_ats`: 前平均成交额（万元/手）
  - `float_share`: 流通股本（万股）
  - `total_mv`: 总市值（万元）

- **筹码数据**：`cyq_perf`（需5000积分权限）
  - `winner_rate`: 筹码胜率（0-100）
  - `cost_concentration`: 筹码集中度 = (cost_95pct - cost_5pct) / (cost_95pct + cost_5pct)

- **融资融券数据**：`margin_detail`
  - `margin_cap_ratio`: 融资余额占比 = 融资余额 / 总市值

- **机构数据**：`top_inst` + `top_list`（近5日）
  - `sum_inst_net`: 5日机构净买入（万元）
  - `list_count`: 上榜次数

**执行方式**：
```python
from newfunction.batch_data_collector import BatchDataCollector
collector = BatchDataCollector()
collector.collect_for_date("20251218")  # 采集T-1数据
```

### 1.2 15分钟线数据导入 (`min15_data_loader.py`)

**目标**：将ZIP压缩包中的15分钟线CSV数据导入到 `min15_cache.db`

**数据格式**：
- 表名：`stock_min15`
- 字段：`trade_time`, `ts_code`, `name`, `open`, `close`, `high`, `low`, `vol`, `amount`, `pct_chg`, `amplitude`
- 数据来源：`newfunction/min15data/*.zip`

**执行方式**：
```python
python newfunction/min15_data_loader.py
```

## 阶段二：初步筛选阶段（日线漏斗策略）

### 2.1 数据加载 (`trading_strategy.py`)

**输入**：
- T日（目标日）日线行情：`pro.daily(trade_date=target_date)`
- T-1日基准数据：从 `t1_data` 表读取

**合并**：将T日行情与T-1基准数据按 `ts_code` 合并

### 2.2 特征工程

**核心指标计算**：
```python
# 基础指标
vol_shares = vol_lots * 100  # 成交量（股）
vwap = amount / (vol_shares + 1e-9)  # 成交量加权平均价
float_mv_cny = total_mv * 10000  # 流通市值（元）

# 核心特征
turnover_rate = (vol_shares / (float_share * 10000 + 1e-9)) * 100  # 换手率
bias = (close - vwap) / (vwap + 1e-9)  # 价格偏离VWAP程度
pct_chg = (close - pre_close) / (pre_close + 1e-9) * 100  # 涨跌幅
efficiency = pct_chg / (turnover_rate + 0.001)  # 效率指标
high_close_dist = (high - close) / (close + 1e-9)  # 高收盘价距离
ats_ratio = ats / (pre_ats + 1e-9)  # 大单异动比率
vol_ratio = vol_lots / (pre_vol + 1e-9)  # 量比
```

### 2.3 漏斗初步筛选（硬性过滤）

**筛选条件**：
```python
mask_funnel = (
    (pct_chg >= 3.0) & (pct_chg <= 8.5) &      # 活跃区间：涨幅3%-8.5%
    (bias > 0.005) &                            # VWAP支撑：价格高于均价0.5%
    (high_close_dist < 0.008) &                 # 尾盘强度：收盘价接近最高价（<0.8%）
    (bid_vol1 / ask_vol1 < 10) &                # 拒绝虚假单：买一/卖一比例合理
    (ats_ratio > 1.2)                           # 大单异动：平均成交额增长>20%
)
```

**逻辑说明**：
- **涨幅区间**：过滤掉涨停和微涨，聚焦中等活跃度股票
- **VWAP支撑**：确保价格在均价上方，有资金支撑
- **尾盘强度**：收盘价接近最高价，说明尾盘有资金抢筹
- **大单异动**：平均成交额显著增长，说明有大资金参与

### 2.4 自适应风控

**市值分层换手率阈值**：
```python
# 大市值股票流动性溢价低，换手率上限需收严
if float_mv_cny > 200亿:
    max_turnover_limit = 8.0%
elif float_mv_cny > 50亿:
    max_turnover_limit = 15.0%
else:
    max_turnover_limit = 20.0%
```

**爆发保护**：
```python
# 排除量比>3且换手>10%的脉冲陷阱
mask_adaptive = (
    (turnover_rate <= max_turnover_limit) &
    ~((turnover_rate > 10.0) & (vol_ratio > 3.0))
)
```

### 2.5 筹码分级系统

**Tier分级**：
```python
Chip_Tier = 0  # 默认

# Tier 1: 绝对顺风（筹码胜率>80%）
if winner_rate > 80:
    Chip_Tier = 1

# Tier 2: 极度集中潜力（胜率60-80%且集中度<0.12）
elif winner_rate > 60 and cost_concentration < 0.12:
    Chip_Tier = 2

# 只保留Tier 1或Tier 2的股票
df = df[df['Chip_Tier'] > 0]
```

### 2.6 量化评分系统

**Final_Score计算**：
```python
# 排名归一化
norm_eff = efficiency.rank(pct=True)      # 效率排名（0-1）
norm_win = winner_rate.rank(pct=True)      # 胜率排名（0-1）
norm_ats = ats_ratio.rank(pct=True)        # 大单异动排名（0-1）

# 加权综合评分
Final_Score = (norm_eff * 0.5) + (norm_win * 0.3) + (norm_ats * 0.2)
```

**排序规则**：
```python
# 优先Tier 1，同Tier内按Final_Score降序
df = df.sort_values(['Chip_Tier', 'Final_Score'], ascending=[True, False])
```

**输出**：取Top 15作为候选股

## 阶段三：15分钟线二次筛选（尾盘体检）

### 3.1 数据获取 (`min15_second_filter.py`)

**数据源**：从 `min15_cache.db` 的 `stock_min15` 表查询

**查询逻辑**：
```python
# 日期格式转换：YYYYMMDD -> YYYY/MM/DD
formatted_date = f"{target_date[:4]}/{target_date[4:6]}/{target_date[6:]}"

# 代码格式转换：000001.SZ -> sz000001
db_code = ts_code.split('.')[1].lower() + ts_code.split('.')[0]

# 查询当天所有15分钟线数据
query = f"""
    SELECT * FROM stock_min15 
    WHERE ts_code = '{db_code}' 
    AND trade_time LIKE '{formatted_date}%' 
    ORDER BY trade_time ASC
"""
```

### 3.2 尾盘体检逻辑 (`check_15min_structure`)

**数据范围**：取最后5根15分钟线（约等于下午13:45-15:00）

**核心检验规则**：

#### Rule A: 均线支撑（价格>VWAP）
```python
# 计算近似VWAP
typical_price = (high + low + close) / 3
cum_value = (typical_price * vol).cumsum()
cum_vol = vol.cumsum()
approx_vwap = cum_value / (cum_vol + 1e-9)

# 当前收盘价必须高于VWAP
is_above_vwap = current_close > current_vwap
```

#### Rule B: 趋势向上（低点抬升）
```python
# 检查最近3根K线的Low是否大体向上
lows = df_tail['low'].values[-3:]
is_trend_up = lows[-1] >= lows[0]  # 最后低点 >= 起始低点
```

#### Rule C: 拒绝避雷针（上影线检查）
```python
# 计算上影线比例
upper_shadow = (high - max(open, close)) / (close + 1e-9)

# 任意一根K线上影线>1.0%则视为危险
has_bad_shadow = (upper_shadow > 0.01).any()
```

#### Rule D: 拒绝阴包阳（势能检查）
```python
# 当前收盘价必须高于3根K线前的开盘价
# 确保下午盘面维持正向走势
start_open = df_tail.iloc[-3]['open']
is_positive_session = current_close > start_open
```

**最终判定**：
```python
if is_above_vwap and is_trend_up and not has_bad_shadow and is_positive_session:
    return True  # PASS
else:
    return False  # FAIL
```

### 3.3 筛选执行

**流程**：
1. 遍历初步筛选的Top 15候选股
2. 对每只股票获取15分钟线数据
3. 执行 `check_15min_structure` 体检
4. 记录PASS/FAIL状态
5. 输出通过筛选的最终名单

## 📈 策略优势

1. **双重过滤**：日线漏斗 + 15分钟线体检，提高选股质量
2. **自适应风控**：根据市值动态调整换手率阈值
3. **筹码分析**：结合筹码胜率和集中度，识别主力控盘
4. **尾盘体检**：通过15分钟线结构检查，过滤尾盘异动陷阱
5. **量化评分**：综合效率、胜率、大单异动，客观排序

---

## ⚠️ 注意事项

1. **数据依赖**：
   - T-1数据需提前采集（使用 `batch_data_collector.py`）
   - 15分钟线数据需提前导入（使用 `min15_data_loader.py`）

2. **权限要求**：
   - 筹码数据（`cyq_perf`）需5000积分权限
   - 机构数据（`top_inst`）需5000积分权限

3. **执行时机**：
   - 建议在T日收盘后（15:00后）执行
   - 确保T日15分钟线数据已完整

4. **数据质量**：
   - 15分钟线数据缺失的股票会被跳过（SKIP）
   - 建议定期检查数据完整性
